# Security policy / Politique de sécurité

## English

**Please do not report vulnerabilities in a public issue.**

Use GitHub's private reporting: the **Security** tab of the repository →
**Report a vulnerability**
(<https://github.com/chla28/CheckScript/security/advisories/new>). Reports may
be written in English or French. Please include the affected version
(`check-script --version`), a minimal script or command to reproduce, and the
impact you foresee.

Only the latest release receives security fixes. This is a personal project:
you will get an acknowledgement as soon as possible, without a guaranteed
delay.

## Français

**Ne signalez pas une vulnérabilité dans une issue publique.**

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt →
**Report a vulnerability**
(<https://github.com/chla28/CheckScript/security/advisories/new>). Les
signalements peuvent être rédigés en français ou en anglais. Indiquez la
version concernée (`check-script --version`), un script ou une commande
minimale pour reproduire, et l'impact envisagé.

Seule la dernière version publiée reçoit les correctifs de sécurité. Il s'agit
d'un projet personnel : un accusé de réception sera envoyé dès que possible,
sans délai garanti.
